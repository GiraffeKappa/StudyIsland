## 三、介面與操作流程

### 學生首頁

首次設定後，開啟即是全畫面讀書島；登入後直接回到島上。

- 頂端精簡顯示今天任務、數學三題完成數、同步狀態。
- 點島嶼開啟該科小鎮；點建築開啟單元，查看熟悉程度、紀錄、備註與跨科關聯。
- 今日任務使用可收合面板。iPad 可在地圖旁顯示；手機橫式收合成入口，需要時開啟，避免遮住全部地圖。
- 主要入口：今日任務、數學練習、錯題本、每週安排、收藏／設定。
- 數學練習與解答使用專注面板，允許展開為全畫面。
- 不依賴滑鼠懸停；提供明確點擊區、雙指操作與地圖按鈕。鍵盤出現時輸入框和提交按鈕仍可見。

### 每週安排

女兒填六、日可用分鐘與平日額外可用時間（預設 0，數學獨立列出）→ AI 提出九科週計畫 → 顯示時間總量及無法容納的項目 → 女兒調整／確認 → 成為正式任務。

既有任務不因 AI 重新建議而被靜默覆蓋。未完成可記部分投入，剩餘量由女兒往後移或確認 AI 改期建議。

### 數學練習

輸入「今天想練……」→ 對應既有單元，歧義時請女兒選擇 → 顯示本次範圍及今日到期錯題 → 出題 → 紙上計算並輸入答案 → 批改、完整步驟 → 錯題入庫 → 顯示今日完成題數。

每日三題以不同題目的首次有效提交計數，答錯也算有練習；同題反覆按送出不重複計數。可繼續練習，不設三題上限。這是建議預設，可於設定調整。

到期錯題可計入三題；若與當天指定範圍不同，清楚列出讓女兒保留、換題或延後，不擅自改變她選的練習範圍。

### 家長畫面

只查看已配對女兒的九科熟悉概況、今日／本週任務、投入分鐘、數學練習與錯題。顯示最後同步時間，不能把離線資料尚未上傳解讀為沒讀書。家長可管理自己的帳號與 AI 服務設定，但不可修改學生學習資料。

## 五、技術方案建議

以下是實作建議，不是額外訪談結論。

- Next.js + React + TypeScript：建立獨立 PWA，替換 grok/canvas，保留原 WebGL/SVG 視覺與互動。
- Supabase Auth + PostgreSQL：帳號、學習資料及家長配對；以資料庫 RLS 和伺服器驗證落實學生可寫、已配對家長只讀。
- Service Worker 快取外殼與必要資產；IndexedDB 保存已載入任務、讀書紀錄及待同步事件。
- 同步在開啟、回到前景、恢復網路時觸發，可加即時更新；不依賴 iOS 背景常駐。
- 新增紀錄採事件追加與唯一 ID；修改任務採版本檢查，遇衝突保留資料並要求選擇，不靜默覆蓋。
- OpenAI Responses API 由伺服器呼叫，模型以環境設定選擇；使用結構化輸出、伺服器欄位和業務規則驗證。
- 金鑰只存伺服器環境，不能放 NEXT_PUBLIC、網頁儲存、Git 或日誌。一般家長只讀權限不等於可寫學生資料。
- 數學公式用適合的公式排版；答案接受合理等價形式，例如分數、根式、多個解，不用字串完全相同判錯。
- 題目生成後先檢查條件與答案一致性，能算術／代數驗證的使用受限驗證器；不可直接 eval 學生或模型文字。無法驗證時標示待確認，不當成確定錯題。
- 題目問題可回報、撤銷錯誤判定、修正錯題與獎勵統計；AI 結構正確不代表數學答案正確。
- 對 AI 請求做驗證、限流、用量記錄、明確錯誤與重試；費用上限尚未指定，做成可設定項，不宣稱已設定平台硬上限。

支援分數、根式、負數、多個解、合理等價答案與常用數學輸入，不以純字串相同判斷。對可確定驗證的題型用受限的計算／代數驗證，禁止 eval 模型或學生文字；需要 AI 輔助時區分不確定判定。題目產生後檢查範圍、條件充分性、答案與步驟一致性，驗證不過重產且限制重試。提供題目有問題回報與修正判定途徑，不宣稱 AI 永不出錯。
答錯自動入錯題本，保留原題、作答、答案、步驟、單元、日期、重練結果。AI 隔日安排重練，算入三題；間隔預設 1/3/7 天，可調。到期錯題若不同於當天指定範圍，顯示並允許保留或延後，不偷偷替換範圍。反覆錯題不重複生成多份錯題紀錄。不確定判定不可當成確定錯題或納入錯誤率。

【介面】
以島為主體，不沿用舊長頁文章排列。iPad 橫式地圖旁為可收合今日任務／單元面板；手機橫式先保持地圖可見，面板按需開啟。入口包括今日任務、數學練習、錯題本、每週安排、收藏／設定。數學題與解答可展開。提供清楚觸控區、safe-area、鍵盤避讓，不能依賴 hover；操作面板時不可同時拖動地圖。家長以閱讀摘要為主，保留查看島嶼入口並標示只讀。

【資料與技術】
建議 Next.js/React/TypeScript、沿用原 WebGL/SVG、Supabase Auth/PostgreSQL/RLS、IndexedDB + Service Worker、OpenAI Responses API 伺服器端串接。先檢查既有專案再決定，若採其他方案說明理由，不為換技術重做美術。
資料至少包含 profiles、guardian_links、subjects、units、textbook_mappings、unit_links、mastery_events、availability、exam_events、plan_versions、tasks、study_logs、focus_sessions、questions、受限制的 question_solutions、attempts、review_items、reward_events、preferences、ai_usage；裝置有 local_outbox。以 student_id 隔離，外鍵與唯一約束維持關聯。共用教材可只讀，未登入不能讀學生資料。家長配對需安全邀請流程，角色與連結不可由客戶端任意改寫。
所有日界線以台北時間計算。事件保留唯一 ID，紀錄追加且重送冪等；任務修改用版本檢查，衝突保留兩份內容並提示處理。離線在已登入、曾載入後可看快取任務並記錄讀書；恢復網路、回前景或重新開啟時同步，不能依賴 iOS 背景同步常駐。退出帳號清除該身份快取，避免跨帳號資料外洩。
離線不能新呼叫 AI；可保留作答草稿待上線批改，不偽造結果。家長看最後同步時間。AI 請求須驗證學生身份與資料所有權，只傳必要單元／表現，不傳家庭姓名、角色私人對話或完整無關備註。
OpenAI 金鑰僅保存在伺服器環境，不放 NEXT_PUBLIC、前端、IndexedDB、Git 或日誌。模型名稱由 OPENAI_MODEL 設定，依實作時官方文件確認；使用結構化輸出但仍驗證語意、日期、單元和負荷。有限重試、限流、用量紀錄和可設定額度；尚未提供預算，不自行承諾費用。數學題生成、判題與排程分開服務。未設定 API 時真實功能顯示尚未設定；示範模式必須明確標示。

【驗收】
- 有效登入後首頁即是原風格 3D 島，角色活動可操作；WebGL 失敗可切 2D，不丟紀錄。
- 分別檢查 iPad 與手機橫式、短高度、軟鍵盤；模擬視窗與實體 Safari 結果分開報告。
- 重整後任務、熟悉程度、備註、分鐘、貼紙仍存在；離線記錄重連只同步一份。
- 番茄鐘切背景再回來可校正，手填和計時器不重複計入。
- 超量排程會被擋／標示；AI 建議確認前不成正式任務；未完成改期保留紀錄。
- 輸入單元可出三題、調難度、等價答案批改、顯示完整步驟、錯題入庫與到期重練；同題重送不重算。
- 家長可在手機看已同步紀錄；實際以家長和未配對帳號嘗試直接 API 寫入／越權讀取，應被拒絕。
- 題目答案提交前無法從學生資料 API 取得；AI 金鑰不出現在前端產物與日誌。
- API 中斷、無額度、輸出不合法、數學無法驗證、同步衝突皆有可恢復狀態，不能假裝成功。
