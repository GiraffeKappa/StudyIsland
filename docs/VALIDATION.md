# 驗證與交付狀態

日期：2026-11-13（Asia/Taipei）。此交付是可建置的本機 PWA 與正式服務整合程式；沒有宣稱已設定外部帳號、跨裝置雲端同步或公開部署。

## 自動驗證

- `pnpm typecheck`：通過。
- `pnpm build`：Next.js 正式建置通過，包含靜態首頁、manifest 與動態 API route。
- `pnpm test`：12 項通過。覆蓋台北日界線、等價分數／根式／多解／負數／指數、禁止任意執行、背景時間戳、零平日容量、超量排程阻擋、事件去重、部分投入、自評分離、任務版本衝突、計時轉紀錄去重、重複計算不修改原計畫、每日同原題去重、題幹／解答的係數驗證，以及 Service Worker 不快取 API／Authorization。
- PostgreSQL 測試使用 **PGlite 執行真正 SQL migrations**，建立學生、家長、未配對帳號及 `auth.uid()` 測試身份。實際檢查未配對者讀不到資料、配對後只讀、直接寫入紀錄／角色／配對表被拒絕、不能直接查解答、一次性邀請無法重用、事件與獎勵冪等、作答重送不重複、回報後撤銷與移除錯題。
- `pnpm test:api`：11 項本機 HTTP 檢查通過。未登入 401、缺 Gemini 503、題目回覆不含答案／解法、提交批改、重送相同 attempt、錯題收錄、重練、`6/2` 等價答案、回報修正、非法科目 400、非自己的／不存在題目 404。
- 來源副本 SHA-256 與來源 metadata 可核對；`.env*`、`.local`、`node_modules`、`.next` 均排除 Git。前端產物以伺服器金鑰測試標記檢查，不應出現該值。

PGlite 的權限與交易測試不等於已在真實 Supabase Auth／PostgREST 服務驗證。需在正式專案完成下述補驗。

## 本機瀏覽器操作

已實際操作：

1. 未配置服務時顯示未設定，僅開放明確標示的本機示範。
2. 第一次設定後進入原生 WebGL 島，角色活動與原圖資存在；可以手動切換 2D 且紀錄保留。
3. 建立本機規則週草稿，按確認後才出現正式任務。
4. 數學示範題在提交前不顯示解答；答錯後計入一次練習並顯示完整步驟與錯題。
5. 保存 12 分鐘與「有做筆記」備註；任務保留 partial。重整後分鐘、備註、自評、任務、練習與獎勵仍存在。
6. 操作過程發現剩餘分鐘重算會修改原計畫，已修正為複製投影，並加入回歸測試。
7. 以 1180×820 平板橫式、844×390 手機橫式檢視地圖與面板；小螢幕面板只占約半幅，地圖仍可見。390×844 直式無水平溢出。
8. 844×260 短高度下實際填寫答案，測量答案框與提交按鈕均在可視區內且無重疊，已保存截圖。這是縮短視窗的鍵盤空間模擬，尚非實體 iOS 鍵盤測試。
9. 正式 production server：首頁、manifest、SW、PNG／Apple icon 皆 HTTP 200，未登入資料 API 為 401，示範入口為 403。

截圖保存在 `docs/`（如有產生）。這些是桌面內嵌瀏覽器的尺寸模擬，**不是實體 iPad 或 iPhone Safari 的結果**。

## 真實服務與實體裝置待補驗

- Gemini：需要實際 key、已啟用模型與使用額度，測出題、單元歧義、排程、改期、拒絕／中斷／額度不足。沒有實際消耗 API 費用。
- Supabase：需要專案連線與 service-role 環境、migrations、seed、Auth 確認信設定。需以真實學生／已配對家長／未配對帳號直接打 REST/API 驗證隔離，再驗證跨手機與 iPad 同步、離線重連去重與衝突處理。
- Safari：實體 iPad／iPhone 的 WebGL 能力、雙指手勢、鍵盤、加入主畫面、首次快取、離線冷啟動、背景／鎖屏／重新開啟後計時校正尚未測試。瀏覽器尺寸模擬不代替實機測試。
- 數學：確定驗證涵蓋一元一次、一元二次與純數值算式。其他概念由 Gemini 出題但標示解答待確認；不聲稱已有涵蓋全課綱的符號代數／幾何驗證器。AI 題目與說明仍需保留回報機制。
- 教材：尚無版次、正式目錄與頁碼；跨冊概念保留原 ID，不冒稱正式翰林／康軒章節。
- 考試日期與範圍未確認，不帶入原硬編碼日期。
- 匯出 JSON 為備份與人工復原用途；目前沒有自動匯入 UI。Supabase 管理者修正與資料庫備份仍應由服務管理者執行。
- 尚未部署，GitHub 原始碼倉庫也不等於正式上線。此版不能直接放 GitHub Pages，需支援 Next.js API 的主機。
